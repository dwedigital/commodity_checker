# Bundled fonts

Latin subsets of the Tariffik brand typefaces, bundled so extension pages never request Google Fonts.

| File | Family | Weights | Source | Licence |
|------|--------|---------|--------|---------|
| `space-grotesk-latin.woff2` | Space Grotesk (variable) | 500, 700 | Google Fonts | SIL Open Font License 1.1 |
| `plus-jakarta-sans-latin.woff2` | Plus Jakarta Sans (variable) | 400–600 | Google Fonts | SIL Open Font License 1.1 |

Same families as the website (`app/assets/tailwind/application.css`).
